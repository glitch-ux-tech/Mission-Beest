Mission BEEST 

Hello there! Mission BEEST is an interactive space game on a website that I developed.

In this game you are playing as Nova. An astronaut sent beyond the borders of Earth to explore other planets and perform some missions. You can customize the appearance of Nova, visit Galaxy Map, receive different missions, collect your achievements and interact with different elements of mission interface.

Project Goal

The purpose of my project is to create something cinematic and interactive instead of just a common webpage and i was really inspired to create this web playable game through many space related movies..
This project actually gave me an opportunity to try to create something interactive instead of just another webpage using the knowledge of HTML, CSS and JavaScript and it was really a awesome journey for me.

Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

 Features

- Cinematic space-themed start
- Nova suit selector
- Mission briefing
- Interactive Galaxy Map
- Planet missions
- Achievements
- Space animations
- Soundtrack
- Interactive mission terminal

 How to Play

Start the mission from the main screen and follow the instructions. Explore the Galaxy Map, choose missions and perform the assigned objectives.
